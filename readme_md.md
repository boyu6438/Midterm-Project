# 會提醒你的智慧藥盒 (NUCLEO-G474RE 期中專題)

時間一到自動閃燈發聲提醒長輩服藥，一鍵按鈕確認並即時記錄上傳 UART。

## 1. 情境故事：誰、在哪、遇到什麼麻煩

* **誰與在哪**：在家中需要每天服用慢性病藥物的長輩，以及在外工作的子女。

* **遇到什麼麻煩**：

  * 長輩記憶力退化，看著藥盒發呆，搞不清楚今天的藥到底吃了沒。

  * 害怕沒吃而重複補吃，造成劑量過高風險；或直接漏吃藥物。

  * 子女在外牽掛，無法即時得知長輩是否有按時服藥。

## 2. 替身對照：故事裡的模組 → 板上替身

* **時間到點提醒**：Timer 模擬定時器 → 時間到達自動切換至提醒狀態。

* **聲光提醒指示**：紅燈亮起 + 蜂鳴器持續發聲 → 提醒長輩服藥。

* **按鈕確認機制**：長輩按下實體按鈕 (EXTI) → 停止蜂鳴器發聲、紅燈切換回綠燈（待機狀態）。

* **雲端/終端紀錄**：UART 傳送確認訊息 → 傳送服藥時間與確認紀錄至電腦終端機供記錄與追蹤。

## 3. 功能與驗收條件：動作、預期、實測結果

| 測試項目 | 觸發動作 | 預期結果 | 實測結果 | 
| ----- | ----- | ----- | ----- | 
| **定時提醒與聲光** | Timer 時間到點 | 紅燈正常亮起，蜂鳴器開始持續發聲發出提醒聲音 | 正常發聲與亮燈 | 
| **按鈕確認解除** | 使用者按下確認按鈕 | 蜂鳴器停止發聲，紅燈熄滅，綠燈亮起並切回待機狀態 | 按下後順利切回待機 | 
| **UART 訊息傳送** | 按下確認按鈕觸發 EXTI | 經由 UART 送出確認服藥的文字紀錄（含狀態與時間資訊） | 終端機成功收到確認訊息 | 

## 4. 用到的技術：第 3～7 週勾選表

* \[x\] **GPIO**：控制 LED 狀態燈號（綠燈=待機；紅燈=提醒中）與讀取按鈕輸入狀態。

* \[x\] **EXTI / NVIC**：按鈕中斷處理，快速回應使用者的確認操作並切換狀態。

* \[x\] **Timer**：計算設定時間，時間到點觸發提醒狀態。

* \[x\] **PWM**：控制蜂鳴器發聲方式與提醒音效。

* \[x\] **UART**：傳送提醒啟動與按鈕確認訊息至電腦終端機，留存服藥紀錄。

## 5. 腳位表：用到的每支腳與用途

* `PA5` = LD2 / 待機綠燈 (GPIO Output)

* `PB0` = 提醒紅燈 (GPIO Output) *(註：請依實際電路腳位調整)*

* `PB1` = 蜂鳴器 PWM 控制 (TIM PWM Output) *(註：請依實際電路腳位調整)*

* `PC13` = B1 使用者按鈕 / 服藥確認鍵 (GPIO EXTI 中斷)

* `PA2` / `PA3` = USART2 TX/RX (ST-LINK VCP 終端機通訊)

## 6. 建置與執行：開發環境、燒錄步驟、終端機設定、命令

* **開發環境**：STM32CubeIDE / NUCLEO-G474RE 開發板

* **終端機設定**：Baud Rate `115200` / Data `8-bit` / Parity `None` / Stop bits `1` (115200 8N1)

* **燒錄與測試步驟**：

  1. 將程式燒錄進 NUCLEO-G474RE 板。

  2. 開啟串口終端機（如 Tera Term / PuTTY 或 STM32CubeIDE Terminal），波特率設為 115200。

  3. 系統預設為**待機狀態**（綠燈亮、蜂鳴器靜音）。

  4. 當 Timer 計時間隔到達，系統進入**提醒狀態**（紅燈亮、蜂鳴器響）。

  5. 按下板上藍色按鈕 (B1)，蜂鳴器停止、綠燈亮起，終端機顯示 `[ACK] Pill Taken!` 服藥紀錄。

## 7. 程式結構：哪個檔做什麼、ISR 與主迴圈分工

* `main.c`：

  * **主迴圈 (main loop)**：處理 FSM 狀態轉換（待機 Idle <-> 提醒 Alert），監控Timer計時與控制 LED 亮滅。

  * **ISR (中斷服務常式)**：

    * `HAL_GPIO_EXTI_Callback()`：按鈕觸發 EXTI 中斷，立即將狀態改回待機、關閉 PWM 蜂鳴器，並透過 UART 送出服藥確認訊息。

    * `HAL_TIM_PeriodElapsedCallback()`：Timer 溢位中斷，切換狀態至提醒狀態並啟動蜂鳴器 PWM。
